# Lagless 0.2.0-rc.8.15 · desktop preview / 桌面预发布版

This preview cleans up the desktop layout and makes new background sessions start reliably on more servers.

### What changed

- New background sessions are created by the terminal connection itself, as when a user runs `tmux`. Previously Lagless started the tmux server from a separate command channel without a terminal, which some systemd servers cleaned up, so the session failed with "server exited unexpectedly". Server-side recording starts as soon as the session exists.
- If the server has no terminal description for `xterm-256color`, the background session falls back to `xterm` instead of failing to start.
- A cleaner desktop style: redesigned welcome page with saved connections, consistent left edges for the session header, side views, bottom input bar, and AI assistant controls, and padding around the terminal text.
- README screenshots are rendered with the application's text settings, so labels are no longer clipped.

### Downloads

- Same packaging as rc.8.14: Windows x64 Native Image desktop ZIP, desktop and terminal ZIPs with bundled runtimes for Windows x64, Linux x64, and macOS arm64, and standalone JARs for Java 21+.
- Update the Windows native edition by extracting the complete ZIP.

### Verification

- Maven tests on Linux with JDK 21: no failures; the only errors are three desktop SSH integration tests that need a real display.
- Background sessions were checked end to end over OpenSSH with tmux 3.4 (Ubuntu 24.04) and tmux 3.2a (Ubuntu 22.04).

### 中文摘要

- 新建后台会话改为由终端连接直接启动 `tmux`，与手动运行 `tmux` 相同。此前 Lagless 从没有终端的独立命令通道启动 tmux 服务，部分使用 systemd 的服务器会将其清理，导致出现 “server exited unexpectedly”。服务器端记录在会话创建后立即开始。
- 服务器缺少 `xterm-256color` 终端描述时，后台会话改用 `xterm`，不再无法启动。
- 界面更简洁：重新设计起始页和已保存连接，会话标题栏、辅助视图、底部输入栏和 AI 助手控件左对齐一致，终端文字四周留出边距。
- README 截图使用与程序相同的文字设置渲染，标签不再被截断。
