# Lagless 0.2.0-rc.8.15 · startup fix / 启动修复

This patch fixes a Windows Native Image startup failure introduced in rc.8.14. The first-run language dialog uses a FlatLaf rounded button border. GraalVM was missing reflection metadata for that border's `arc` field, so the EXE could fail before showing the workspace. The metadata is now registered, and native verification opens and dismisses the real first-run dialog.

The standalone core and terminal edition are unchanged in behavior. This release keeps the Windows native desktop package and bundled-runtime desktop/terminal packages for Windows x64, Linux x64, and macOS arm64.

If rc.8.14 fails at startup, download the **complete** `lagless-desktop-native-0.2.0-rc.8.15-windows-x64.zip`, close Lagless, and replace the existing installation with the extracted bundle. An app that cannot open cannot start its built-in updater.

## Build and verification

- Windows Native Image: built with official Oracle GraalVM 25.0.5. The native verifier now exercises the first-run language dialog and workspace before checking SSH, updates, and rollback.
- Bundled-runtime Windows packages use official Oracle JDK 25.0.5.0.2. Linux x64 and macOS arm64 packages reuse the checksum-verified Oracle JDK 25.0.5.0.2 runtimes from rc.8.14 and include the new application JARs. Linux launchers are checked in WSL; macOS execution is not checked on a macOS host.
- GitHub Actions remain disabled; artifacts are built and checked locally. No refreshed Linux native executable is included.

## 中文

修复 rc.8.14 Windows 原生版首次启动时的报错：语言选择界面的圆角按钮访问 FlatLaf 的 `arc` 字段，但原生包缺少相应反射配置。本版补充配置，并让原生构建验证实际打开、关闭首次语言选择界面。

如果旧版无法启动，请下载完整的 Windows 原生 ZIP，退出 Lagless 后解压替换安装目录。无法启动的旧版本无法通过内置更新器自助升级。终端核心的运行逻辑没有改动。
