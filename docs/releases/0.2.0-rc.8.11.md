# Lagless 0.2.0-rc.8.11

- 修复 core 行编辑模式将远端提示符的原位重绘误记为新历史行的问题；切换兼容模式不再让 JLine 自动绘制空白行。
- 软件日志记录终端尺寸变更与提示符重绘，并继续记录实际写入 SSH 的回车，方便区分显示问题和远端收到命令。
- AI 助手支持在输入框直接粘贴剪贴板图片，以及选择图片、PDF、TXT、MD 文件。
- AI 助手可逐份多选终端输出、软件运行、终端历史日志。参考资料区域明确显示所选文件，日志内容只随本次请求发送。
- 保留独立 core 与仅终端安装包。Windows 原生桌面包使用 Oracle GraalVM 25.0.5，含运行时的桌面和终端包使用 Oracle JDK 25.0.5.0.2。

本版本继续作为预发布版。完整安装包请在 GitHub Release 下载；更新原生桌面版时应使用整个 ZIP 包。
