# Lagless 0.2.0-rc.1 · Windows 预发布版

保留独立低延迟 SSH 核心和纯终端安装方式，新增可选桌面客户端。本次为预发布版本，供 Windows x64 用户手动体验和反馈。

## 下载与启动

- `lagless-desktop-native-0.2.0-rc.1-windows-x64.zip`：推荐的 Windows 原生桌面包。完整解压后双击 `Lagless.exe`，无需安装 Java；必须保留同目录 DLL 与其他配套文件。
- `lagless-0.2.0-rc.1-windows-x64.zip`：包含精简 Java 运行时的桌面包，通过 `lagless.cmd gui` 启动，也可使用命令行模式。
- `lagless-terminal-0.2.0-rc.1-windows-x64.zip`：独立终端版及精简运行时，不包含图形客户端；在已有终端运行 `lagless.cmd user@host`。
- `lagless.jar` / `lagless-terminal.jar`：分别为桌面与终端可运行 JAR，需要 Java 21 或更高版本。
- `lagless-core.jar`：供集成使用的独立核心库，依赖由项目 Maven 配置描述。
- `SHA256SUMS.txt`：上述附件的 SHA-256 校验值。

下载地址以本 GitHub Release 附件为准，不同安装方式的目录与文件请分别保留。

## 主要变化

- 将项目拆分为 `core`、`cli`、`desktop` 模块，终端版继续独立安装，保留本地编辑、异步补全及全屏交互回显预测。
- 桌面端支持 SSH 连接库、多窗口、多连接标签、导入已有终端配置、跳板账号选择及后台跳板连接。编辑连接保持原顺序，支持拖动排序并保存。
- 本地命令编辑支持底部单行、右侧和独立窗口，支持高度调整、自动换行与剪切复制粘贴；发送后移除已提交内容。
- Windows 使用 DirectWrite / Direct2D 绘制终端与日志正文；调整字体、中文输入法定位、光标和滚动呈现。同步刷新期间保留上一完整画面，避免显示中间清空帧。
- Codex / Claude 等实时交互模式的日志和回滚合并逐字增长前缀，保留正文变化；支持远端滚轮协议及翻页兼容方式。本地长期历史写入磁盘，不以固定行数截断。
- 软件日志统一记录本地操作和已提交命令，支持前台查看、分页、查找、跟随最新及导出；旧版本日志仍可查看。
- 双栏文件管理支持加载提示、新建文件夹、本地软件打开文件、复制、粘贴、剪切、重命名、确认删除和文件夹传输；提供进度队列、限速、取消及重试。跨端剪切在传输成功且源元数据未变化后删除源文件。
- 提供账号导入导出、加密备份恢复、更新回滚、插件、按需 AI / 翻译、命令审阅及多 SSH 上下文协作。AI 服务需自行配置。
- 启动窗口居中，标签页改为紧凑圆角样式；新增「关于」菜单，可查看版本并直接打开 GitHub 项目。

## 验证状态与边界

本次仅完成源码编译、Windows x64 GraalVM Native Image 构建、运行时打包及文件完整性检查。按本次开发要求，未运行测试、SSH 验收或启动应用；历史验收报告不代表此版本已通过回归。此版本标为 Pre-release，不替代现有稳定版。

远端执行和应用翻页仍受网络及服务器响应影响。SSH 完全断开后，纯客户端不能保留服务器 PTY；可选复用服务器已有 tmux。远端文件通过本地软件打开的是下载副本，修改后需主动上传。队列不跨重启恢复，重试从头开始。原生插件机制与各平台限制见项目文档。

Linux/macOS 不提供本次 Windows 二进制适用性保证；相关平台须单独构建并验收。
