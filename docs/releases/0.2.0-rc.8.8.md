# Lagless 0.2.0-rc.8.8

- AI 服务地址支持填写 API 根地址或 `/v1`，自动请求 OpenAI 兼容的 `/chat/completions` 路由，并在 404 时显示实际请求地址。
- 修复菜单操作可能将 Enter 继续发送到终端，以及兼容模式无法切换的问题。
- 备份恢复期间显示全局阻塞式进度窗口；完成后提示结果，备份文件保留。
- 明确提供交互程序滚轮发送 PageUp / PageDown 的选项；修正终端中文字形上沿裁切，并改进管理按钮图标与列表选中对比度。

终端和 JVM 桌面包使用官方 JDK 25.0.5.0.2。Windows 原生包使用 Oracle GraalVM 25.0.4，并在构建时应用、校验及嵌入 Oracle 官方证书阻止文件，缓解 CVE-2026-91403；原生包未包含整个 JDK 25.0.5.0.2 的其他修复。

构建产物和验证范围以本次发布执行结果为准。
