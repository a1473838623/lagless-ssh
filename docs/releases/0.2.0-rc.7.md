# Lagless 0.2.0-rc.7 · Windows 桌面整合预览版

本版汇总此前 rc1–rc6 的桌面功能和修复，加入光标小幅加长、垂直居中的调整。GitHub 上的 rc1–rc6 发布与附件由本版替代；代码提交、标签和历史说明保留。现有 0.1.x 正式版继续保留。

## 保留低延迟核心

`core`、`cli`、`desktop` 独立分层。低延迟本地行编辑、异步补全、本地历史及交互回显预测继续由原有核心提供；只使用终端时，无需安装图形客户端，也无需在服务器安装 Lagless。

## 桌面功能汇总

- 多窗口与并发 SSH 标签；按需打开连接库，读取已有终端配置，支持账号导入导出、跳板账号选择和后台跳板连接。编辑连接保持原顺序，可手动拖动排序。
- 本地命令编辑支持底部单行、右侧与独立窗口，共享草稿；支持调节高度、自动换行、撤销及剪切复制粘贴。Enter / Ctrl+Enter 发送全部文本，Shift+Enter 换行；成功进入输入队列后清空并记录软件日志。
- 前台日志查看、分页、查找、跟随最新与导出；软件日志合并本地操作和已提交命令。终端回滚写入磁盘，实时刷新历史合并逐字增长前缀，并保留正文变化。
- 双栏 SFTP 文件管理提供加载状态、新建文件夹、本地软件打开、复制粘贴、剪切、重命名、确认删除和文件夹传输；队列显示进度，支持限速、取消和重试。
- 自动重连、加密备份恢复、整包更新与回滚、输出镜像、翻译、AI 插件、命令审阅及多 SSH 上下文协作。AI 服务需自行配置。

## 合并修复与本次调整

- 终端光标基于字体大写字高小幅加长，在行格内垂直居中，并对齐像素；原生和兼容显示均保留细竖线与闪烁效果。
- Windows 使用 DirectWrite / Direct2D 绘制终端与日志。修复编辑器拖动时终端画布预清背景的绘制路径，保留已呈现帧，合并密集拖动更新，并固定终端区域高度；不增加额外按键。
- 中文编辑字体与终端字体分开选择，检查中文字形覆盖；Windows 剪贴板使用 Unicode 字符传递，保留其他平台的兼容路径。
- 在终端粘贴的内容留在终端，不再转移到本地编辑框。真实换行在粘贴或编辑器发送前可选择合并为一行、保留或取消；视觉自动折行不触发提示。
- Codex、Claude Code 等实时刷新程序中的编辑器发送默认开启，保留逐次确认；确认期间连接或输入模式改变则保留草稿。关闭交互发送时明确提示，不误报为断线。
- RC 更新器查询预发布渠道，正确比较 RC 与正式版顺序。安装助手使用独立完整运行库，确认就绪后提供「重启并应用更新」；受保护的 Windows 安装目录使用用户目录暂存并请求 UAC 权限。窗口显示实际安装路径与安装结果。

## 升级

rc5 / rc6 可使用「下载更新 → 允许所需权限 → 重启并应用更新」。rc4 及更早版本的旧更新器若无法替换程序，需要先关闭全部 Lagless 进程，手动将本版完整覆盖到实际安装目录一次。Program Files 需要管理员权限。EXE、DLL 与清单必须来自同一完整发行包，不能只替换 EXE。

## 验证与限制

本版完成 Java/C++ 编译、Windows x64 GraalVM Native Image 构建、运行时打包及发行文件校验。按当前要求，未执行测试、启动应用、连接 SSH、改写系统剪贴板或触发真实升级。光标、拖动与交互发送的实际效果仍需实机确认，因此继续作为 Pre-release。

远端执行、翻页与重连仍受网络和服务器响应影响。SSH 完全断开后，纯客户端不能保留服务器 PTY，可选复用服务器已有 tmux。远端文件通过本地软件打开的是下载副本；队列不跨重启恢复，重试从头开始。Linux/macOS 需要分别构建并验收，本次附件仅覆盖 Windows x64。
