# Lagless 0.2.0-rc.8.14 · desktop preview / 桌面预发布版

This preview focuses on input and display in full-screen tools such as Claude Code and Codex CLI. It keeps the independent terminal edition alongside the desktop workspace.

### What changed

- More reliable local echo when an interactive program redraws or moves its input box, plus cleanup of stale Chinese input method preedit text.
- An English desktop interface, chosen on first launch and changeable under About → Language; refreshed controls and tabs.
- Ctrl+C copies selected terminal text and preserves real line breaks while joining soft-wrapped rows. Without a selection, Ctrl+C still interrupts the remote program.
- Optional background sessions using `tmux` already on the server, or installed there only after confirmation. Lagless can reconnect later and import output recorded while it was closed.
- The Windows native EXE starts reliably on first run: GraalVM reflection metadata for the FlatLaf rounded button border used by the language dialog is registered.
- Light, dark, and system-following desktop themes, with updated pill-style connection tabs. Theme changes apply to open windows without restarting.
- Native Windows rendering recovers its Direct2D target after device loss. AI assistant replies can turn line wrapping off and select recent terminal and log context more precisely.

### Downloads and build provenance

- Windows x64: newly built Native Image desktop ZIP, plus desktop and terminal ZIPs with bundled runtimes.
- Linux x64 and macOS arm64: desktop and terminal ZIPs containing the new Java application and the exact Oracle JDK 25.0.5.0.2 runtime from the checksum-verified rc.8.13 bundles. Unix launcher and bundled Java execution permissions are corrected. No refreshed Linux native binary is published with this release.
- Standalone desktop, terminal, and core JARs are included for Java 21+ environments. Release ZIPs and JARs have SHA-256 checksums.
- The Windows native program was compiled with official Oracle GraalVM 25.0.5. The bundled JVM runtimes use official Oracle JDK 25.0.5.0.2.

### Verification

- Windows Maven tests on the patched Oracle JDK: 195 tests, no failures or errors, five skips (including the POSIX-only `tmux` shell test).
- Windows Native Image: real desktop/SSH verification and native update, installation, and rollback checks passed. The native verifier also opens and dismisses the real first-run language dialog and switches themes.
- Linux x64 desktop and terminal ZIPs launched in WSL with their bundled JDK and reported this version. macOS arm64 ZIP permissions and contents were checked, but no macOS host was available to launch them.
- GitHub Actions remain disabled; these assets were prepared and checked locally.

### 中文摘要

- 改善 Claude Code、Codex CLI 等全屏程序重绘时的输入显示，修复中文输入法预编辑残留；新增英文桌面界面并调整样式。
- 终端选中文字时 Ctrl+C 复制，自动换行的内容可连续复制，真正的换行仍保留；未选中文字时 Ctrl+C 仍向远端发送中断。
- 新增可选的 `tmux` 后台会话：用户确认后检查或安装服务器上的 `tmux`，退出客户端后会话继续运行，重新连接时导入离线期间的输出。
- 修复 Windows 原生版首次启动时语言选择界面报错（补充 FlatLaf 圆角按钮的原生反射配置），原生验证会实际打开并关闭该界面。
- 新增浅色、深色和跟随系统的界面主题，连接标签调整为圆角样式；切换主题时无需重新启动窗口。
- Windows 原生渲染器可在设备丢失后恢复；AI 助手增加回复换行开关和更灵活的上下文选择。
- 本次提供 Windows 原生包、Windows/Linux/macOS 含运行时桌面与终端包，以及独立 JAR；Linux 原生包未在此版本重新构建。更新 Windows 原生版时请解压完整 ZIP。
