# Lagless 0.2.0-rc.8.6

- 连接库改为单击选择，提供可见的管理入口和上移 / 下移排序。
- 修复 AI 地址输入省略协议时默认补 HTTPS、404 错误诊断、AI 服务可用性测试和设置窗口的输入法拼音显示。
- 修复插件管理页未展示内置 AI 插件的问题，并将插件加载、运行和错误记录到软件日志。
- 修复打开或关闭 AI 视图导致 SSH 发送空行；普通 shell 滚轮只浏览 Lagless 本地终端历史。
- 交互程序滚轮默认使用远端鼠标协议逐行滚动；远端不支持时默认发送方向键逐行滚动。可在视图菜单选择改用 PageUp / PageDown。
- 备份跳过临时日志文件并把实时日志尾部并入快照。恢复时保留备份文件和当前运行中的日志；文件选择器只接受已完成的 `.llbackup` 文件。
- 普通 Swing 输入框增加输入法预编辑文字绘制；调整交互程序滚轮设置的作用范围和说明。

Windows JDK 运行时使用官方 JDK 25.0.5.0.2。原生 EXE 使用 Oracle GraalVM 25.0.4 并应用官方证书阻止列表，缓解 CVE-2026-91403；原生构建不包含完整 JDK 25.0.5.0.2 安全修复。

仅编译和静态检查，未启动图形客户端。
