# Lagless 0.2.0-rc.3 · 中文字形与预发布更新修复

## 本次修复

- 修复本地编辑框中的中文显示为带问号方框：之前强制使用不具备中文字形的 Consolas，文本本身仍完整，复制出去会显示原文。编辑器现在优先选择具备中文字符覆盖的字体，终端的等宽网格字体独立保留。
- 修复 rc1 / rc2 更新器漏掉预发布版本：旧程序只访问 GitHub 稳定版 `latest` 接口。新版 RC 客户端查询已发布版本列表，选择最新的预发布或正式版；稳定版客户端仍只使用稳定渠道。
- 修正版本比较规则：`rc.2 < rc.10 < 正式版`，构建元数据不影响版本顺序；跳过草稿发布。
- 「关于 Lagless」新增实际剪贴板服务状态，区分 Windows Unicode 已启用和缺少新版原生库的兼容路径。
- 保留 rc2 的 Windows Unicode 剪贴板读写。此前把字体缺字判断为编码损坏，rc2 没有处理编辑框字体，本版补上该修复。

## 下载与升级

**rc1 / rc2 的旧更新器自身有缺陷，首次升级需要手动下载并完整解压本版，不能依赖旧版“检查更新”。以后 RC 更新可继续检测预发布渠道。**

- 推荐：`lagless-desktop-native-0.2.0-rc.3-windows-x64.zip`，完整解压后双击 `Lagless.exe`，无需安装 Java。
- `lagless-0.2.0-rc.3-windows-x64.zip`：含精简 Java 运行时的桌面包，运行 `lagless.cmd gui`。
- `lagless-terminal-0.2.0-rc.3-windows-x64.zip`：独立终端及运行时，不需要图形客户端。
- `lagless.jar` / `lagless-terminal.jar`：桌面与终端 JAR，需要 Java 21+。
- `lagless-core.jar`：供集成使用的独立核心库。
- `SHA256SUMS.txt`：附件 SHA-256 校验值。

原生桌面程序和 `lagless-render.dll` 必须来自同一个完整发行包，避免仅复制 EXE/JAR 后仍加载旧组件。安装路径会改变时，请启动本版目录中的程序，勿继续使用指向旧目录的快捷方式。
