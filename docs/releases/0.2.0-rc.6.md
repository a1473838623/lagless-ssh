# Lagless 0.2.0-rc.6 · 拖动闪烁与交互程序发送

## 本次修复

- 修复拖动本地编辑器时终端输出文字仍闪烁的一条绘制路径：AWT 的 Canvas 在调用画布绘制前会预先清除受损区域。现在仅在本项目原生画布创建时关闭该画布的预清背景，创建后恢复原有系统属性；终端和日志画布都由自己的完整帧覆盖背景。
- Direct2D 保留已经呈现的帧，窗口调整与曝光期间不再主动丢弃上一帧；字体、字号、网格和逐帧完整绘制方式保持原有设置。
- 编辑区拖动的窗口高度更新合并到约 16ms 一次，松开时立即应用最后高度；继续固定终端区域尺寸，不借用终端空间，也不发送额外按键。拖动不再丢弃此前尚未同步给 SSH 的尺寸。
- 修复 Codex、Claude Code 等实时刷新程序中本地编辑器无法发送：交互程序发送现在默认开启，保留逐次目标确认；关闭该功能时明确提示，不再误报为连接未就绪。
- shell、交互程序发送前都检查实际 SSH 通道；确认期间连接或输入模式改变则保留草稿并要求重试。整段发送、成功后清空、记录软件日志和真实换行检查继续保留。

## 下载与更新

- `lagless-desktop-native-0.2.0-rc.6-windows-x64.zip`：推荐的 Windows 原生程序，完整解压后运行 `Lagless.exe`。
- `lagless-0.2.0-rc.6-windows-x64.zip`：含 Java 运行时的桌面版。
- `lagless-terminal-0.2.0-rc.6-windows-x64.zip`：独立终端与运行时。
- 桌面、终端、核心 JAR，以及 `SHA256SUMS.txt`。

rc5 用户可使用「下载更新 → 重启并应用更新」。本次包含 `lagless-render.dll` 修改，请使用完整发行包。rc4 及更早版本的旧更新器若无法替换程序，仍需手动完整覆盖一次。

## 验证状态

仅完成 Java/C++ 编译、Windows 原生打包和发行文件校验；按当前要求未运行测试、启动程序或连接 SSH。拖动时的显示效果与 Codex / Claude Code 的实际输入效果仍需实机确认，继续作为预发布版本。
