# Lagless 0.2.0-rc.8.9

- AI 助手可添加可搜索 PDF 附件，本机提取文字后随请求发送；扫描版 PDF 会提示当前不支持 OCR。文件解析在后台进行。
- 移除兼容模式与辅助视图切换期间的 Enter 拦截。切换输入模式时不再强行把键盘焦点抢回终端，避免菜单 Enter 的尾随事件落入 SSH 输入队列。
- 将菜单命令延迟到当前按键事件派发完成后执行；修复 AI/插件/文件管理窗口没有正确绑定工作区 owner 的问题，避免无主窗口干扰焦点。
- 修复备份恢复在 macOS `/var` 系统路径为符号链接时错误拒绝恢复的问题，同时继续拒绝恢复目标目录内部的符号链接。
- 修正终端跨行选区复制时带入整屏尾部空格；更新过时的多行编辑发送测试，验证完整草稿按用户选择合并后整体提交。
- GitHub Actions 在 Linux 使用虚拟显示运行图形交互测试；原生构建改用 Oracle 官方修复的 GraalVM 25.0.5 归档（官方 SHA-256 固定校验；安全公告将该更新称为 25.0.5.0.2）。
- Windows 原生程序通过实际 Native Image 构建与启动验收，包含 PDF 文本提取、SSH/跳板/SFTP、终端回滚、加密备份和原生更新替换测试。

桌面/命令行运行包使用 Oracle JDK 25.0.5.0.2；Windows 原生包使用同一安全更新线的 Oracle GraalVM Native Image。PDF 支持通过 Apache PDFBox 3.0.8 实现。

PDF 仅提取可搜索文字：单个文件最多 12 MiB、300 页、1,000,000 个字符；无文字的扫描 PDF 需要先 OCR。附件文字会作为上下文发送到所选 AI 服务。
