# Lagless 0.2.0-rc.8.10

- 修复 Windows 原生版 GitHub Actions 验收中进程退出、临时目录清理和输入审计造成的失败；Windows 和 Linux Native Image 构建已通过。
- 改进 AI 助手的会话选择与布局，修正终端模式切换和辅助视图焦点处理，减少意外向 SSH 发送空行的情况。
- 改进终端会话、SFTP 传输和插件进程的收尾处理，使关闭窗口和自动化验收更稳定。
- 保留独立 core 与仅终端安装包。Windows 原生桌面包使用 Oracle GraalVM 25.0.5，含运行时的桌面和终端包使用 Oracle JDK 25.0.5.0.2。

本版本继续作为预发布版。完整安装包请在 GitHub Release 下载；更新原生桌面版时应使用整个 ZIP 包。
