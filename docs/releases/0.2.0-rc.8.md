# Lagless 0.2.0-rc.8 · 官方 JDK 与证书安全更新

本版针对 CVE-2026-91403 更新运行时及原生构建中的证书阻止数据，保留 rc.7 的功能与低延迟核心；不改变 SSH 输入、回显、重连和界面逻辑。

## 两种构建的安全处理

**附带运行时的桌面版和独立终端版**使用未经修改的 Oracle JDK **25.0.5.0.2+1-LTS-2**（2026-10-21），由官方完整修复包构建。

**Windows 原生 EXE**使用 Oracle GraalVM **25.0.4+7.1**，在独立构建副本中应用 Oracle 官方 `blocked.certs`，随后重新编译。原生构建检查在初始化阶段比较 JDK 实际加载的全部 **86 个证书指纹**与官方文件，确认相同并在构建时初始化以嵌入 EXE。报告保存在包内 `security/native-blocklist-build.json`。不依赖旧 EXE 读取旁置文件，也没有手写证书指纹或混装不同 JDK 的类库。

这是 Oracle 针对该 CVE 提供的官方应急缓解路径；**基础原生编译器仍是 25.0.4，不等同于完整 JDK 25.0.5.0.2 更新，也不包含后续其他安全修复。**`build-jdk.json` 如实记录实际版本、证书 SHA-256、措施类型及 `fullJdkSecurityBaselineSatisfied: false`。完整修复 GraalVM 可用后应重新构建。

## 官方来源与校验

- [Oracle CVE-2026-91403 公告](https://www.oracle.com/security-alerts/alert-cve-2026-91403.html)
- [Oracle 应急方案](https://ops.java/emudhra)：允许替换 JDK 的 `lib/security/blocked.certs`。
- [GraalVM 证书说明](https://www.graalvm.org/latest/reference-manual/native-image/dynamic-features/CertificateManagement/)：原生编译会捕获构建时的证书及阻止数据。
- 官方修复 JDK ZIP：`https://download.oracle.com/java/25/archive/jdk-25.0.5.0.2_windows-x64_bin.zip`
- JDK ZIP SHA-256：`9b11e644a31d9775379d76a1a985b806e8457b96b4ff49516ea5f4c7cffaa6af`。
- 证书文件原样取自该 ZIP 的 `jdk-25.0.5.0.2/lib/security/blocked.certs`，SHA-256：`101200f8ff64a4375a03601cf0200d0f9fec449d1a173aaf1459a5765ae7e5ae`。
- 原版 GraalVM ZIP SHA-256：`5198b29a6448cb72b9a3cef10866723e2d1e2ec4799561a344e032bb7c61e555`；源记录及构建校验保存在仓库 `security/cve-2026-91403/` 和原生包内 `security/`。

发行脚本默认拦截旧 JDK。原生的证书缓解例外仅允许经过校验的 Windows x64 Oracle GraalVM 25.0.4 与固定校验值的官方文件，不将其他旧版本一概放行；不修改用户系统安装的 Java。

## 附件与升级

| 附件 | 用途 |
| --- | --- |
| `lagless-desktop-native-0.2.0-rc.8-windows-x64.zip` | 原生桌面版，完整解压后双击 `Lagless.exe`，无需 Java；采用上述证书缓解措施 |
| `lagless-0.2.0-rc.8-windows-x64.zip` | 含官方完整修复 JDK 的桌面版，运行 `lagless.cmd gui` |
| `lagless-terminal-0.2.0-rc.8-windows-x64.zip` | 含官方完整修复 JDK 的独立终端版 |
| `lagless.jar` / `lagless-terminal.jar` / `lagless-core.jar` | 需要使用者提供已修复的运行时；仅替换 JAR 不会升级 Java |
| `SHA256SUMS.txt` | 附件 SHA-256 校验值 |

原生 rc5–rc7 可通过「下载更新 → 重启并应用更新」完整替换新原生包。早期更新器若无法升级，请关闭全部窗口，手动完整解压覆盖；Program Files 需要相应权限。

**运行时版必须完整替换 ZIP 中的运行时。**旧更新器仅替换 JAR 的路径不能完成本次安全升级。rc.7 原生包及其证书数据不因系统 Java 升级而改变。

## 构建与限制

本次完成 Java/C++ 编译、Windows x64 Native Image 编译、编译阶段证书捕获检查、运行时打包及文件完整性核对。按用户要求未运行测试、启动 GUI、连接 SSH、操作系统剪贴板或执行真实安装更新；新工具链下的实际界面交互仍需实机确认，因此保持 Pre-release。本次附件仅覆盖 Windows x64。
