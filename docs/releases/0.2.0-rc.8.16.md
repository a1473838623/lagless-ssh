# Lagless 0.2.0-rc.8.16 · desktop preview / 桌面预发布版

This preview polishes menus and pop-ups, makes rollback explicit about its target, and hardens background sessions.

### What changed

- Menu text lines up: plain, check, radio, and submenu items share one text column. Previously check and radio items sat 4 px further left than plain items.
- Menus, tooltips, and dropdowns close when you switch to another application, instead of staying above its windows.
- The start-page tab no longer sits against the window edge, and the home page buttons sit closer to the connection field.
- Rollback names the version it restores. Each in-app update now records the version it replaced; if the current version was installed by extracting a ZIP, Lagless warns that the saved backup is older than the version used just before.
- Before offering background sessions, the server check starts a throwaway tmux session to confirm tmux can actually run. When it cannot (for example on a server out of memory), Lagless explains why and shows how to add swap, instead of failing with "server exited unexpectedly" on every attach.
- Background sessions start tmux in its own systemd user scope when the server offers one, so the end of an SSH login cannot take tmux with it. If a background session ends right after attaching twice in a row, Lagless stops retrying and writes read-only server diagnostics to the Application log.

### Downloads and build provenance

- Windows x64: Native Image desktop ZIP, plus desktop and terminal ZIPs with a bundled runtime. Linux x64 and macOS arm64: desktop and terminal ZIPs with a bundled runtime. Standalone desktop, terminal, and core JARs for Java 21+. All files have SHA-256 checksums in `SHA256SUMS.txt`.
- Every file is built by this repository's GitHub Actions workflows from the tagged commit, on GitHub's Windows, Linux, and macOS runners, with the official Oracle JDK 25.0.5.0.2 (`scripts/install-release-jdk.ps1`) and, for the Windows EXE, the hash-pinned Oracle GraalVM (`scripts/install-native-graalvm.ps1`).
- Update the Windows native edition by extracting the complete ZIP.

### Verification

- Windows Maven tests on Oracle JDK 25.0.5.0.2: 201 tests, no failures or errors, seven skips (including the POSIX-only tmux tests).
- Windows Native Image: real desktop/SSH verification passed, including the first-run language dialog and the light/dark theme switch.
- Linux x64 and macOS arm64 bundles were built on their own runners; they were not launched there.
- Background sessions were checked over OpenSSH with tmux 3.4, including the fallback on a server without a systemd user manager.

### 中文摘要

- 菜单文字对齐：普通项、勾选项、单选项和子菜单共用同一文字列（此前勾选/单选项比普通项靠左 4 像素）。
- 切换到其他程序时自动关闭菜单、提示和下拉框，不再停留在其他程序窗口之上。
- 起始页标签不再贴着窗口边缘，主页按钮更靠近连接选择框。
- 回滚会显示将恢复的版本；程序内更新会记录被替换的版本，若当前版本是手动解压安装的，会提示保存的备份比上一个使用的版本更旧。
- 所有安装包由 GitHub Actions 从标记的提交构建；Windows 测试 201 项全部通过（7 项跳过，含仅限 POSIX 的 tmux 测试），原生 EXE 通过真实桌面/SSH 验证。
- 打开后台会话前，服务器检查会启动一个临时 tmux 会话，确认 tmux 能正常运行；若无法运行（例如服务器内存不足），会说明原因并给出添加交换空间的方法，不再在每次连接时反复报 “server exited unexpectedly”。
- 后台会话在服务器支持时于独立的 systemd 用户 scope 中启动 tmux，SSH 登录结束不会连带结束 tmux；若连续两次刚连接就结束，将停止重试并把只读的服务器诊断写入软件日志。
