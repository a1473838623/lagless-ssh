# Lagless 0.2.0-rc.8.12

- 修复 Claude Code 等全屏程序滚动时客户端逐行绘制、卡顿的问题。客户端合并远端画面更新，避免每段输出都扫描整屏并保存尚未画完的文字。
- 终端历史和 SSH 会话输出按短时间内的同一画面去重；稍后再次出现的相同内容仍会保留。原始全屏控制流仍可按记录设置保存。
- 日志查看改为滚动自动读取较早或较晚的内容，能从最新输出一路查看完整历史；移除“较早”“较晚”“最新”按钮。
- “跟随最新”只在实际可见内容变化时滚动，不再因定时刷新而跳到底部。
- 保留独立 core 与仅终端安装包。Windows 原生桌面包使用 Oracle GraalVM 25.0.5，含运行时的桌面和终端包使用 Oracle JDK 25.0.5.0.2。

本版本继续作为预发布版。完整安装包请在 GitHub Release 下载；更新原生桌面版时应使用整个 ZIP 包。
