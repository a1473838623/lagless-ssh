# Lagless 0.2.0-rc.8.23 · Windows preview / Windows 预发布版

A fix for text typed in Claude Code when it asks a question.

### What changed

- In Claude Code, text typed at the empty input prompt was lost when Claude Code then showed a question with options (such as a permission prompt) and you chose one. Lagless keeps such text locally until Enter. Claude Code hides the cursor while a question is shown, and Lagless only noticed the prompt had gone while the cursor was visible, so it kept drawing your text over the question and took the keys meant for it: an arrow key sent the text into the question, where it was lost, and a digit was added to the text instead of choosing an option.
- Now, when the prompt row shows something else with the cursor hidden, your text steps aside: the question stays visible, the keys that choose an option go to Claude Code, and the text comes back, still unsent, when the prompt returns. The row must show other content for at least 150 ms, so a screen redraw is not taken for a question.

### Downloads and build provenance

- Windows x64 only: Native Image desktop ZIP, desktop and terminal ZIPs with a bundled runtime, and standalone desktop, terminal, and core JARs for Java 21+. On Linux or macOS use the JARs with Java 21+, or the rc.8.16 bundles.
- Built by this repository's GitHub Actions workflows on GitHub's Windows runner from the tagged commit, with the official Oracle JDK 25.0.5.0.2 and, for the EXE, the hash-pinned Oracle GraalVM. All files have SHA-256 checksums in `SHA256SUMS.txt`.
- Update the Windows native edition with Check for updates, or by extracting the complete ZIP.

### Verification

- The full Maven test suite passed before release on Linux with JDK 21. New tests choose an option with the arrow keys and Enter and with a digit (both failed on rc.8.22 and pass now), and check that a redraw which briefly replaces the prompt does not take typed keys.
- On the Windows runner, the finished EXE ran its update check against GitHub with `gh` removed from PATH. The test suite is not run on GitHub, to save Actions minutes.

### 中文摘要

- 修复 Claude Code 中在空输入框输入文字后，Claude Code 弹出带选项的问题（如权限确认）并选择选项时，已输入文字丢失的问题。Lagless 会在本地保留这些文字直到按 Enter；Claude Code 显示问题时会隐藏光标，而此前 Lagless 只在光标可见时检查输入框是否被替换，因此仍把文字画在问题上，并截获了选择选项的按键：方向键会把文字发送给问题而丢失，数字键则被加入文字而没有选择选项。
- 现在，输入框所在行在光标隐藏时显示其他内容，输入的文字会暂时让开：问题正常显示，选择选项的按键发给 Claude Code，输入框恢复后文字仍在（尚未发送）。该行需显示其他内容至少 150 毫秒，避免把普通重绘误认为问题。
