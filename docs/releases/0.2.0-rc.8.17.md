# Lagless 0.2.0-rc.8.17 · Windows preview / Windows 预发布版

A small update for the Windows desktop and the terminal edition: window resizes no longer close Lagless, and folder transfers show real progress.

### What changed

- Resizing the window while typing into a full-screen program (such as Claude Code) could throw inside local echo and end the terminal edition, closing its console window. Edits made on a wider row are now clipped to the new width. If local echo ever fails again, the connection logs it and continues without prediction instead of exiting.
- Folder transfers count their size faster: the scan reuses the attributes in each folder listing instead of one extra request per file, and shows the running total while counting.
- Transfer progress shows files done out of the total and one decimal below 10 %, so a large folder no longer appears stuck at 0 %.
- The transfer queue shows each task's source (From) and destination (To); hover for the full path.

### Downloads and build provenance

- Windows x64 only: Native Image desktop ZIP, desktop and terminal ZIPs with a bundled runtime, and standalone desktop, terminal, and core JARs for Java 21+. Linux and macOS bundles are not published for this release; on those systems use the JARs with Java 21+, or the rc.8.16 bundles.
- Built by this repository's GitHub Actions workflows on GitHub's Windows runner from the tagged commit, with the official Oracle JDK 25.0.5.0.2 and, for the EXE, the hash-pinned Oracle GraalVM. All files have SHA-256 checksums in `SHA256SUMS.txt`.
- Update the Windows native edition by extracting the complete ZIP.

### Verification

- The full Maven test suite passed before release on Linux with JDK 21 (core, terminal, and desktop, including real SSH and SFTP integration tests), plus a 20,000-run randomized resize stress test of local echo.
- The release workflows skip the test suite to save Actions minutes. The Windows native build still runs the application once on the JVM to record Native Image metadata; the finished EXE was not re-verified on the runner.
