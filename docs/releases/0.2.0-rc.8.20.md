# Lagless 0.2.0-rc.8.20 · Windows preview / Windows 预发布版

Fixes the window going black and freezing after Claude Code has been idle.

### What changed

- After Claude Code had been idle for a while, the next interaction turned the terminal black and froze it for a long time. The freeze watchdog added in rc.8.19 captured the cause: the UI thread was busy updating the Output mirror. An idle Claude Code keeps repainting its spinner and status line with cursor moves rather than new lines, so the mirror's text grew into one enormous line that was re-wrapped completely on every update, every 150 ms, even while the mirror was hidden. The mirror now updates only while it is shown (output waits in its bounded buffer, which keeps the latest 128,000 characters, and appears when you open the mirror), and runs longer than 2,000 characters get a line break.

### Downloads and build provenance

- Windows x64 only: Native Image desktop ZIP, desktop and terminal ZIPs with a bundled runtime, and standalone desktop, terminal, and core JARs for Java 21+. On Linux or macOS use the JARs with Java 21+, or the rc.8.16 bundles.
- Built by this repository's GitHub Actions workflows on GitHub's Windows runner from the tagged commit, with the official Oracle JDK 25.0.5.0.2 and, for the EXE, the hash-pinned Oracle GraalVM. All files have SHA-256 checksums in `SHA256SUMS.txt`.
- Update the Windows native edition with Check for updates, or by extracting the complete ZIP.

### Verification

- The full Maven test suite passed before release on Linux with JDK 21, including a new test that feeds the mirror 3,000 idle repaints and checks that a hidden mirror is not touched and no line exceeds 2,000 characters. The native build's verification run also passed on the JVM.
- On the Windows runner, the finished EXE ran its update check against GitHub with `gh` removed from PATH. The test suite is not run on GitHub, to save Actions minutes.
