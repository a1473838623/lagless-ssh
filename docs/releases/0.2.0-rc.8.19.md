# Lagless 0.2.0-rc.8.19 · Windows preview / Windows 预发布版

A fix for editing in Claude Code, and a diagnostic for UI freezes.

### What changed

- In Claude Code, after accepting a suggestion with Tab and editing it, moving the cursor to the start of the input and typing a character replaced the whole text with that one character. Lagless edits Claude Code's prompt locally only while it is empty, which it judged by whether everything after the cursor was blank or faint (Claude Code's placeholder hint). That check also took 24-bit colours such as `38;2;r;g;b` for faint text, and an accepted suggestion is drawn in such a colour, so the text was treated as a placeholder. The colour codes are now read properly: only text that is actually faint counts as a placeholder, and accepted suggestions are treated as your input.
- When the window stays black or frozen for more than 3 seconds, Lagless now writes what its UI thread was doing, and how long the freeze lasted, to the Application log (View ▸ Application log). This only observes; it is there to find the cause of the freeze some users see after Claude Code has been idle.

### Downloads and build provenance

- Windows x64 only: Native Image desktop ZIP, desktop and terminal ZIPs with a bundled runtime, and standalone desktop, terminal, and core JARs for Java 21+. On Linux or macOS use the JARs with Java 21+, or the rc.8.16 bundles.
- Built by this repository's GitHub Actions workflows on GitHub's Windows runner from the tagged commit, with the official Oracle JDK 25.0.5.0.2 and, for the EXE, the hash-pinned Oracle GraalVM. All files have SHA-256 checksums in `SHA256SUMS.txt`.
- Update the Windows native edition with Check for updates, or by extracting the complete ZIP.

### Verification

- The full Maven test suite passed before release on Linux with JDK 21. New tests cover the Tab-suggestion case (it fails on rc.8.18 and passes now), faint versus coloured text, and the freeze watchdog.
- On the Windows runner, the finished EXE ran its update check against GitHub with `gh` removed from PATH. The test suite is not run on GitHub, to save Actions minutes.
