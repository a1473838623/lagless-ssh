# Lagless 0.2.0-rc.4 · 粘贴、整段发送与编辑区拖动

## 本次修复

- 终端内粘贴始终进入终端，不再将多行内容转交本地编辑框，也不改动本地草稿。断线时拒绝发送，不转移粘贴目标。
- 终端多行粘贴和本地编辑器发送共用真实换行检查：可以将换行替换为空格，以一条逻辑行自动折行显示；也可以保留多行或取消。自动换行产生的视觉折行不会触发提示。终端粘贴仍移除末尾换行，不额外提交回车。
- 本地编辑器的 Enter / Ctrl+Enter 发送全部文本，不受光标所在行或选区影响。完整内容成功进入输入队列后立即清空共享草稿，并记录到软件日志；取消、未连接和队列拒绝时保留草稿。底部、右侧和独立编辑窗行为一致。
- 发送文本时遵循终端的括号粘贴模式，使多行文字进入本地行编辑器或支持该协议的远端程序时保持一个完整输入块；仍保留危险命令检查和交互程序确认。
- 底部编辑区拖动改用固定终端画布尺寸的布局，消除调整窗口下沿过程中短暂挤压终端的中间布局；减少无关区域重绘。向下扩展窗口与编辑区，向上缩小至一行，不给远端发送额外输入。

## 下载

- `lagless-desktop-native-0.2.0-rc.4-windows-x64.zip`：Windows 原生客户端，完整解压后运行 `Lagless.exe`。
- `lagless-0.2.0-rc.4-windows-x64.zip`：含 Java 运行时的桌面客户端，运行 `lagless.cmd gui`。
- `lagless-terminal-0.2.0-rc.4-windows-x64.zip`：独立终端与运行时，保留无图形客户端的使用方式。
- 同时提供桌面、终端、核心 JAR 和 `SHA256SUMS.txt`。

rc3 的更新器支持检测本版；rc1 / rc2 用户仍需手动下载并完整解压。不要只替换 EXE，请保持原生库与程序来自同一发行包。

## 验证状态

仅执行 Java/C++ 编译、Windows 原生打包和发行文件校验。按当前要求未运行测试、启动应用、连接 SSH 或改写系统剪贴板。拖动时的实际显示效果需实机确认，本版继续作为预发布版本。
