# Lagless 0.2.0-rc.5 · 原生自动更新安装流程修复

## 本次修复

- 安装目录不可写（例如 Program Files）时，下载与暂存可放在用户目录；仅安装助手通过 Windows 的标准 UAC 提示申请权限。取消权限提示时不替换当前程序。
- 更新助手复制完整运行库到独立目录，避免缺少 DLL，或加载并占用待替换的安装文件。助手确认启动并验证暂存包后，界面才显示已就绪。
- 更新窗口新增「重启并应用更新」：保存草稿与日志、关闭全部工作区，等待原进程退出，替换当前安装目录中的完整原生包，再打开新版客户端。重启由原用户权限的进程执行。
- 修复辅助对话框关闭时仅隐藏，以及关闭工作区后旧进程可能仍存在的问题；原生客户端退出前等待日志、草稿和连接清理，释放程序文件。
- 更新期间再次打开程序时转交等待流程，减少旧进程再次占用安装文件的问题。助手等待同一安装目录的其他客户端退出；超时和安装失败写入结果文件。
- 更新窗口显示实际安装路径、运行版本、上次安装结果和日志位置，区分下载就绪与安装成功。保留原生整包备份和失败回滚机制。

## 首次升级

**rc4 及更早版本仍运行旧更新器，本版无法改变旧进程的安装权限和退出逻辑。旧更新器替换失败时，需要手动下载、关闭全部 Lagless 进程，并将完整原生包覆盖到实际安装目录一次。Program Files 需要管理员权限。不要只复制 EXE。**

新版安装后，后续更新通过「下载更新 → 允许所需权限 → 重启并应用更新」完成。
