# Lagless 0.2.0-rc.8.21 · Windows preview / Windows 预发布版

File details and sorting in the file manager.

### What changed

- Each file row can show its **Size**, **Modified** and **Created** time in aligned columns. A **Details** checkbox turns them on or off (on by default).
- Both file lists can be sorted by name, size, modified or created time, ascending or descending, with folders always first. The sort and the Details setting are remembered.
- Remote sizes and modified times come with the folder listing Lagless already fetches, so no extra requests are made. The SFTP protocol used by OpenSSH (version 3) does not report creation time, so remote rows show "—" for Created. Local details are read once, in the background, when a folder loads.

### Downloads and build provenance

- Windows x64 only: Native Image desktop ZIP, desktop and terminal ZIPs with a bundled runtime, and standalone desktop, terminal, and core JARs for Java 21+. On Linux or macOS use the JARs with Java 21+, or the rc.8.16 bundles.
- Built by this repository's GitHub Actions workflows on GitHub's Windows runner from the tagged commit, with the official Oracle JDK 25.0.5.0.2 and, for the EXE, the hash-pinned Oracle GraalVM. All files have SHA-256 checksums in `SHA256SUMS.txt`. Workflow artifacts are now kept for one day only.
- Update the Windows native edition with Check for updates, or by extracting the complete ZIP.

### Verification

- The full Maven test suite passed before release on Linux with JDK 21, including a new test of the sort order. The native build's verification run, which opens the file manager, passed on the JVM.
- On the Windows runner, the finished EXE ran its update check against GitHub with `gh` removed from PATH. The test suite is not run on GitHub, to save Actions minutes.
