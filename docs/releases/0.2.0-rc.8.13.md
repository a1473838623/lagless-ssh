# Lagless 0.2.0-rc.8.13 · desktop preview / 桌面预发布版

**Choose this release for the current desktop preview.** It includes Windows x64 and Linux x64 Native Image packages, bundled-runtime desktop and terminal editions for Windows x64, Linux x64, and macOS arm64, standalone JARs, checksums, and the independent core JAR. The 0.2 line is still a pre-release. Extract the full ZIP when updating the native Windows app.

### Highlights

- Ordinary terminal history now focuses on shell input/output, while the full SSH history preserves readable interactive output and submitted local commands. Application events have a separate run log.
- The desktop workspace retains the independent terminal core, with local editing, connection profiles, SFTP transfers, and optional assistant/plugin views.
- Windows native desktop was built with Oracle GraalVM 25.0.5; bundled-runtime packages use Oracle JDK 25.0.5.0.2.

See the [English overview](../../README.md), [中文说明](../../README.zh-CN.md), [UI gallery](../gallery.md), and [consolidated history](../../CHANGELOG.md). Documentation changes after this tag do not change these binaries.

### 中文更新内容

- 终端历史专注普通命令行输入输出，保留独立的重复行和当前屏幕尾部；Codex、Claude Code 等全屏实时重绘不再进入这一历史。
- 全量输入输出历史保留普通 SSH 输出、可读的交互画面和已提交的本地命令。默认另存完整原始远端控制流，日志窗口可单独导出；透传逐键及隐藏提示输入不单独记录，避免保存密码。
- 日志分类统一为「终端历史」「全量输入输出历史」「软件日志」，移除旧版本本地命令分类；旧文件仍保留在磁盘。
- GitHub Actions 去掉跨系统重复单元测试和 Windows 重复编译；原生构建仍保留 JVM 元数据采集、真实 SSH/界面及更新回滚验证。
- 保留独立 core 与仅终端安装包。Windows 原生桌面包使用 Oracle GraalVM 25.0.5，含运行时的桌面和终端包使用 Oracle JDK 25.0.5.0.2。

本版本继续作为预发布版。更新原生桌面版时应使用整个 ZIP 包。
