# Lagless 0.2.0-rc.8.4

Windows 原生 ZIP 可解压后运行 `Lagless.exe`。本版修改桌面端；SSH 核心和仅终端安装方式保持独立。

- 连接菜单的「添加」不再带加号，去掉窗口内重复的 Lagless 文字；Windows EXE 嵌入与窗口一致的图标。
- 滚轮设置合并为「交互程序中用滚轮滚动内容」。普通 shell 的滚轮查看本地长期历史；交互程序优先使用其鼠标滚轮协议，不支持时使用该程序的翻页键。Shift+滚轮始终翻本地历史。原先「滚轮优先操作远端」开关已移除。
- 透传改称「强制键盘透传（当前连接）」，通常无需手动开启。切换模式时不再通过本地预测器的普通重置路径提交队列里的回车。输出镜像仅改变本地视图；打开和关闭不主动发送命令。远端 shell 可能在终端尺寸变化时重新绘制提示符。修复 `ESC[>4;m` 被误当成颜色指令传入本地提示符的问题；这是远端 shell 的键盘协议控制序列，不应显示为 `4;m`。
- AI 设置支持添加、编辑、删除、切换服务配置；每个配置可填写多个模型并直接输入 API 密钥。助手调用时选择配置和模型，翻译时选择源语言与目标语言。四种功能的提示词可编辑；结果仍先进入本地草稿，由用户审阅。
- Windows 上密钥在用户目录以 DPAPI 保护；其他平台限制配置文件权限。完整加密备份内保存可恢复的配置，恢复到新 Windows 用户时会重新保护密钥。旧 `assistant.properties` 的服务地址和模型继续读取，原有环境变量密钥需在新界面填写。
- 插件界面增加安装/导入、导出、启用/禁用、配置、卸载和离线开发指南。进程插件 ZIP 包可携带描述文件及可执行文件；配置作为 JSON 提供给进程或 JVM SPI。详见 `docs/plugins.md`。

可执行包仍使用 [rc.8.3 说明](0.2.0-rc.8.3.md)中列出的官方 JDK 25.0.5.0.2 运行时和 GraalVM 25.0.4 官方证书阻止文件缓解方案；原生 EXE 不等于完整 JDK 25.0.5.0.2 安全修复。

按用户要求，仅编译、打包及静态校验；未启动图形客户端、SSH 服务、自动更新或测试。
