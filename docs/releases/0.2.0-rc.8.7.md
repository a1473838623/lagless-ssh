# Lagless 0.2.0-rc.8.7

- 修复终端滚动时清除文字选区的问题。选区现在绑定到历史中的绝对行列，滚动或回到最新画面时仍可复制。
- 复制可以跨越本地历史页与当前终端画面；按住 Shift 点击或拖动可从原锚点继续扩展选区。

运行时包使用官方 JDK 25.0.5.0.2。Windows 原生 EXE 使用 Oracle GraalVM 25.0.4，并在构建时应用、校验及嵌入 Oracle 官方证书阻止文件，缓解 CVE-2026-91403；原生包未包含整个 JDK 25.0.5.0.2 的其他修复。

按用户要求未运行测试或手工启动 GUI。发布构建过程会记录其实际构建结果。
