# Lagless 0.2.0-rc.8.1 · SSH 私钥文件选择

本版是 rc.8 的小版本更新。新建和编辑 SSH 配置时，可点击私钥栏旁的「选择文件…」，直接选择本地私钥，自动填入完整路径；也保留手动填写路径。

文件窗口优先定位已有路径或用户的 `.ssh` 目录，可显示隐藏文件，允许选择无扩展名的私钥。只允许选择文件，取消选择保持原内容；仅保存文件路径，不导入或复制私钥内容。

更新器已有的版本比较逻辑支持 `rc.8 < rc.8.1 < rc.9`，本次不改变更新协议、SSH 核心或终端交互逻辑。

## 安全构建与附件

沿用 [rc.8 安全构建方案](0.2.0-rc.8.md)：Windows 原生版使用 Oracle GraalVM 25.0.4+7.1，并在构建时应用、校验和嵌入 Oracle 官方证书阻止文件，针对 CVE-2026-91403 提供官方缓解措施；这不等于完整更新基础 GraalVM 的其他安全补丁。桌面及终端运行时包使用官方完整修复的 Oracle JDK 25.0.5.0.2。

| 附件 | 用途 |
| --- | --- |
| `lagless-desktop-native-0.2.0-rc.8.1-windows-x64.zip` | 原生桌面版，完整解压后运行 `Lagless.exe`，无需安装 Java |
| `lagless-0.2.0-rc.8.1-windows-x64.zip` | 含运行时的桌面版，运行 `lagless.cmd gui` |
| `lagless-terminal-0.2.0-rc.8.1-windows-x64.zip` | 含运行时的独立终端版 |
| `lagless.jar` / `lagless-terminal.jar` / `lagless-core.jar` | 对应 JAR，需要使用者提供已修复的运行时 |
| `SHA256SUMS.txt` | 附件校验值 |

原生 rc.8 可通过软件内更新功能完整升级，或关闭全部窗口后手动完整解压替换。旧运行时版本的安全升级仍需完整替换包含运行时的 ZIP，不能仅替换 JAR。

按用户要求仅编译打包并核对文件，未运行测试、启动 GUI、连接 SSH、操作系统剪贴板或执行真实安装更新。本次附件仅覆盖 Windows x64，文件选择窗口的实际交互需实机确认，因此继续作为 Pre-release。
