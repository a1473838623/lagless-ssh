# Lagless 0.2.0-rc.8.5

Windows 原生 ZIP 可解压后运行 `Lagless.exe`。本版修复桌面端；SSH 核心和仅终端安装方式保持独立。

- AI 设置窗口使用 Lagless 图标。AI 服务允许本机与私有局域网 IPv4 地址使用 HTTP，包括 `192.0.2.97`；公共地址仍须使用 HTTPS。使用 HTTP 时，API 密钥在局域网传输中不加密。
- 连接库点击任意账号时立即选中，提供明确的「编辑所选」和「上移 / 下移」按钮，并保留拖动排序。起始页「管理连接」改为醒目的按钮。

可执行包仍使用 [rc.8.3 说明](0.2.0-rc.8.3.md)中列出的官方 JDK 25.0.5.0.2 运行时和 GraalVM 25.0.4 官方证书阻止文件缓解方案；原生 EXE 不等于完整 JDK 25.0.5.0.2 安全修复。

按用户要求，仅编译、打包及静态校验；未启动图形客户端、SSH 服务、自动更新或测试。
